# Decisions log

Every decision and assumption that shapes the project, so nothing is argued twice. Newest at the bottom. Status is `accepted`, `assumed` (a reversible default waiting for confirmation) or `superseded`.

| ----- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| D-001 | 2026-09-21 | Phase 1 installs `node_modules` locally (~550 MB); Blender, KTX encoding and renders run in GitHub Actions or a cloud session from phase 3. | The working session runs on the owner's PC. | D-002 | 2026-09-21 | Repository `larrymijo/kelor-mascot`, public.                                                                                                | Public repos get unlimited GitHub Actions minutes, which the Blender pipeline needs. | D-004 | 2026-09-21 | TypeScript 5.9 and ESLint 9, not TypeScript 7 and ESLint 10.                                                                                | They are what create-next-app 16.3.5 pins and what Next 16 is tested with. Revisit in phase 7.                                            | accepted |
| D-005 | 2026-09-21 | pnpm 12.4.2 through corepack, pinned in `packageManager`. Same major everywhere.                                                 | accepted |
| D-007 | 2026-09-21 | Ambient occlusion uses the separate `n8ao` package (phase 2).                                                                               | @react-three/postprocessing 3.1 does not bundle N8AO, contrary to the original stack note.                                                | accepted |
| D-008 | 2026-09-21 | Site copy in Spanish (`lang="es"`), code and docs in English. Copy lives in `src/lib/copy.ts`.                                              | Audience is Spanish-speaking; one copy file keeps a future translation cheap.                                                             | assumed  |
| D-009 | 2026-09-21 | `robots: noindex, nofollow` until launch (phase 8).                                                                                         | Previews and the placeholder must not be indexed.                                                                                         | accepted |
| D-010 | 2026-09-21 | Montserrat (display) and IBM Plex Sans (text) through `next/font/google`, self-hosted at build time.                                        | Same families as the existing KELOR site; `next/font` removes layout shift and third-party requests.                                      | assumed  |
| D-011 | 2026-09-21 | Zod is a dev dependency. Runtime code reads `character.json` through a type-only import.                                                    | Keeps ~15 kB of validation code out of the client bundle; CI validates the JSON instead.                                                  | accepted |
| D-012 | 2026-09-21 | The GLB validator has zero dependencies and parses the GLB container itself.                                                                | Runs on plain Node in CI in seconds, without pulling gltf-transform into phase 1.                                                         | accepted |
| D-013 | 2026-09-21 | Both eyes share one `eyes` mesh and both lids one `eyelids` mesh, each part weighted 100 % to its bone.                                     | Keeps the model at 6 draw calls instead of 9, while the eyes remain separate geometry driven by their own bones.                          | accepted |
| D-014 | 2026-09-21 | Medium quality tier runs N8AO at half resolution; low disables it.                                                                          | 60 fps on an Intel integrated GPU at `medium` is the target; baked AO in `body_orm` covers the mascot on `low`.                           | accepted |
| D-015 | 2026-09-21 | Playwright uses the installed Chrome (`channel: 'chrome'`) and is not part of CI in phase 1.                                                | Zero browser downloads on the owner's disk. The placeholder has no behaviour worth an e2e gate yet.                                       | accepted |
| D-016 | 2026-09-21 | Security headers without HSTS preload or CSP for now.                                                                                       | Vercel already serves HSTS. A CSP must allow the WASM and worker decoders (Meshopt, Basis) added in phase 4, so it is written in phase 7. | accepted |
| D-017 | 2026-09-21 | LF line endings enforced with `.gitattributes`.                                                                                             | The host sets `core.autocrlf=true`, which would break `prettier --check` in CI.                                                           | accepted |
| D-018 | 2026-09-21 | GLB hosting (`public/` vs Cloudflare R2 or Vercel Blob) decided in phase 4.                                                                 | Depends on the real file sizes after compression.                                                                                         | assumed  |
